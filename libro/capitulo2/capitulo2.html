Capítulo 2: Conceptos fundamentales

Conceptos básicos

HTML se encarga de la estructura de la página, CSS de su aspecto y JavaScript de su comportamiento. Estos tres lenguajes son la base de cualquier sitio web.

Contenido avanzado

Una vez dominadas las bases, se pueden usar tablas, formularios, diseño adaptable y otras técnicas para crear páginas más completas.

Ejemplos prácticos

Practicar con ejemplos reales, como una página personal o un pequeño libro digital, ayuda a consolidar todo lo aprendido.

HTML y la WWW

El HTML es el lenguaje de marcas utilizado para crear y organizar el contenido de las páginas que forman la WWW.

Funcionamiento de HTML

Gracias a HTML, los navegadores pueden interpretar y mostrar el contenido de forma estructurada, combinando textos, imágenes, hipervínculos y otros elementos multimedia.

Origen de la WWW

La WWW fue desarrollada por Tim Berners-Lee, quien también creó la primera versión de HTML.

Tim Berners-Lee explicó:

La Web es más una creación social que técnica.

Comunicación en la web

Para acceder a una página web se utiliza normalmente el protocolo HTTP o su versión segura, HTTPS. Estos protocolos permiten la comunicación entre el navegador y el servidor donde se encuentra alojada la página.

Puedes encontrar más información en la página del W3C .
